# EsoMcp.NET

A local .NET 10 MCP server for Elder Scrolls Online. Query tools read SQLite. An explicit refresh imports observations through [EsoData.NET](https://github.com/JuliusJacobsohn/EsoData.NET).

> Created with substantial help from **OpenAI Codex** and tested against my own use cases. Please do not treat this project as a measure of my abilities as a developer, for better or worse.

Implementation is underway. No account data or game catalog is distributed in this repository.
